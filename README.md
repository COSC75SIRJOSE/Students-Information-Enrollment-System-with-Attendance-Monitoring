# Students-Information-Enrollment-System-with-Attendance-Monitoring

**Course:** COSC_75_BACK_END_DEVELOPMENT

## About the Project

A Laravel-based Students Information and Enrollment System with Attendance Monitoring.

## Technologies Used

- Laravel
- PHP
- MySQL
- HTML, CSS, and JavaScript
- Vite

## Local Development Setup

1. Install PHP, Composer, Node.js, and MySQL.
2. Clone or download this repository.
3. Run `composer install`.
4. Copy `.env.example` to `.env`.
5. Configure your database settings in `.env`.
6. Run `php artisan key:generate`.
7. Run `php artisan migrate`.
8. Run `npm install` and `npm run build`.
9. Start the development server using `php artisan serve`.

## Security

Do not commit your `.env` file, database passwords, or other sensitive credentials.
